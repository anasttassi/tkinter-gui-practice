# Практика по GUI на Tkinter (Тема 18)
Репозиторий содержит решения трёх заданий по созданию графических интерфейсов на Python с
использованием библиотеки `tkinter`.
## Состав проекта
- `calculator.py` — **Задание 18.1.1.** Калькулятор с поддержкой клавиатурного и кнопочного ввода.
- `patients_app.py` — **Задание 18.1.2.** Форма учёта пациентов с расчётом ИМТ, сохранением в JSON и
сводной статистикой.
- `fastqc_app.py` — **Задание 18.1.3.** Точка входа с опцией `--fastq-gui` для запуска графического
анализатора FASTQ («Урезанный FastQC»).
- `biotools/` — модуль работы с последовательностями из группового проекта (`__init__.py`, `base.py`,
`fastq.py`) и его графический интерфейс (`fastq_gui.py`).
- `data/test.fastq` — тестовый FASTQ-файл для проверки задания 18.1.3.
- `README.md` — описание проектов, инструкции по запуску и воспроизводимые примеры.
## Установка зависимостей
Для `calculator.py` дополнительные пакеты не нужны (используются только встроенные модули `tkinter` и
`math`).
Для `patients_app.py` и `fastqc_app.py` (`biotools`) используются:
- `matplotlib` — построение статистических графиков;
- `pandas` — обработка табличных данных в модуле `biotools/fastq.py`;
- `faker` *(опционально)* — генерация реалистичных тестовых ФИО в `patients_app.py` (без него работает
встроенный генератор);
- `tkinterdnd2` *(опционально)* — поддержка перетаскивания файлов мышкой (Drag & Drop) в
`biotools/fastq_gui.py`.
```bash
pip install matplotlib pandas faker
```
Для включения Drag & Drop в «Урезанном FastQC» дополнительно установите:
```bash
pip install tkinterdnd2
```
*(На Linux при отсутствии системного пакета Tk может потребоваться `sudo apt install python3-tk`.)*

## Задание 18.1.1 — Калькулятор (`calculator.py`)
Графический калькулятор на `tkinter`.
### Возможности
- Ввод выражений как с клавиатуры, так и с помощью кнопочной панели (`0`–`9`, `.`, `+`, `-`, `*`, `/`,
`sqrt`, `C`, `DEL`, `=`).
- Горячие клавиши: `Enter` — вычислить (`=`), `Esc` — очистить (`C`).
- Собственный разбор и вычисление выражений без `eval()` с учётом приоритета операций (`*` и `/`
выполняются раньше `+` и `-`).
- Валидация ввода: пустая строка, недопустимые символы, лишние десятичные точки, два знака операции
подряд, незавершённые выражения.
- Обработка исключений: деление на ноль и извлечение квадратного корня из отрицательного числа.
### Запуск
```bash
python calculator.py
```
### Минимальные воспроизводимые примеры
1. **Приоритет операций:** введите `2 + 3 * 4` и нажмите `=` (или `Enter`) → результат `14`.
2. **Смешанный ввод (клавиатура + кнопки):** введите с клавиатуры `15`, нажмите кнопку `/`, введите
`3`, нажмите `=` → результат `5`.
3. **Квадратный корень:** введите `25` и нажмите кнопку `sqrt` → `sqrt = 5`.
4. **Редактирование и очистка:** кнопка `DEL` удаляет один последний символ, `C` (или `Esc`) полностью
очищает поле.
5. **Деление на ноль:** введите `10 / 0` и нажмите `=` → сообщение `Ошибка: Деление на ноль
невозможно.`.
6. **Корень из отрицательного числа:** введите `-9` и нажмите `sqrt` → сообщение `Ошибка: Нельзя
извлечь квадратный корень из отрицательного числа.`.
7. **Валидация некорректного ввода:** введите `abc` и нажмите `=` → сообщение `Ошибка: Недопустимый
символ: 'a'.`.

## Задание 18.1.2 — Формы учёта-отчёта (`patients_app.py`)
Приложение для ведения таблицы пациентов, автоматического расчёта индекса массы тела (ИМТ) и
визуализации сводной статистики.
### Возможности
- Таблица пациентов (`ttk.Treeview`) с полями: `ФИО`, `Возраст`, `Пол`, `Рост (см)`, `Вес (кг)`, `ИМТ`
и сортировкой по клику на заголовок столбца.
- Модальная форма добавления и редактирования пациента с отдельными полями `Фамилия*`, `Имя*`,
`Отчество (при наличии)`, выбором пола (`Мужской`, `Женский`, `Не определён`) и проверкой корректности
ввода.
- Автоматический расчёт ИМТ по формуле `вес (кг) / (рост (м))²`.
- Сохранение данных в файл `patients.json` при каждом изменении и автоматическая загрузка при запуске
программы.
- Кнопка `Примеры (+20)` для быстрой генерации тестовых записей (`faker` / `random`).
- Кнопка `Статистика` — окно с 4 графиками `matplotlib`:
1. Распределение пациентов по полу.
2. Распределение пациентов по возрасту.
3. Распределение ИМТ с учётом пола.
4. Зависимость ИМТ от возраста.
### Запуск
```bash
python patients_app.py
```
### Минимальные воспроизводимые примеры
1. **Добавление пациента и расчёт ИМТ:** нажмите `Добавить`, заполните `Фамилия`: `Иванов`, `Имя`:
`Пётр`, оставьте `Отчество` пустым, возраст `30`, пол `Мужской`, рост `180`, вес `81`, нажмите
`Сохранить` → в таблице появится строка `Иванов Пётр` с `ИМТ = 25.00`.
2. **Третий вариант пола:** выберите в поле `Пол` значение `Не определён` → запись корректно
сохраняется и отображается на всех графиках статистики.
3. **Валидация формы:** оставьте обязательное поле `Фамилия` пустым или введите буквы в поле `Возраст`
→ появится сообщение об ошибке, некорректная запись не сохранится.
4. **Редактирование и сохранение в файл:** выберите строку, нажмите `Редактировать` (или дважды
кликните по строке), измените вес и сохраните → пересчитается ИМТ и обновится `patients.json`; после
перезапуска программы все данные сохранятся.
5. **Генерация выборки и статистика:** нажмите `Примеры (+20)`, затем `Статистика` → откроется окно с 4
графиками по всем добавленным пациентам.

## Задание 18.1.3 — Урезанный FastQC (`fastqc_app.py`, `biotools/fastq_gui.py`)
Графический интерфейс для модуля работы с FASTQ-файлами (`biotools/fastq.py`) из группового проекта.
### Возможности
- Работа напрямую через класс `FastqReader` и накопитель статистики `FastqStats` из `biotools.fastq`
(однопроходное чтение `.fastq`, `.fq`, `.fastq.gz`, `.fq.gz`).
- Специальная опция интерфейса для запуска GUI под формат FASTQ: `--fastq-gui` (или `--gui`), а также
консольный режим `--cli`.
- Диалог выбора файлов (`filedialog.askopenfilename`) с фильтром по форматам (`.fastq`, `.fq`,
`.fastq.gz`, `.fq.gz`) и проверкой расширения.
- Опциональная поддержка перетаскивания файлов мышкой (**Drag & Drop**) при установленной библиотеке
`tkinterdnd2`.
- Сводка по открытому файлу (количество ридов, минимальная/максимальная/средняя длина, средний балл
качества Phred, GC-состав) и 4 вкладки с интерактивными графиками `matplotlib`:
1. **Качество (Phred)** (`Per base sequence quality`) — график среднего качества по позициям с
цветовыми зонами FastQC.
2. **Нуклеотиды** (`Per base sequence content`) — доля `A`, `C`, `G`, `T`, `N` на каждой позиции.
3. **Длины ридов** (`Sequence length distribution`) — распределение длин последовательностей.
4. **Все графики** — общий экран со всеми 3 графиками сразу.
- Кнопка `Сохранить PNG` для выгрузки 3 графиков в выбранную папку через `FastqReader.plot_all()`.
### Запуск
```bash
# Запуск графического интерфейса через специальную опцию для формата FASTQ:
python fastqc_app.py --fastq-gui
# Запуск с автоматическим открытием конкретного файла:
python fastqc_app.py --fastq-gui -f data/test.fastq
# Прямой запуск модуля GUI:
python -m biotools.fastq_gui
# Консольный режим (вывод сводки без открытия окна):
python fastqc_app.py --cli -f data/test.fastq
```
### Минимальные воспроизводимые примеры
1. **Выбор файла через диалог с фильтром:** запустите `python fastqc_app.py --fastq-gui`, нажмите
`Открыть FASTQ...` (в фильтре типов файлов выбраны `*.fastq *.fq *.fastq.gz *.fq.gz`), откройте
`data/test.fastq` → отобразится сводка (`Ридов: 5`, `Длина: 10–30 (ср. 16.0)`, `Ср. Phred: 39.3`, `GC-
состав: 45.0%`) и построятся графики.
2. **Просмотр статистических графиков:** переключитесь между вкладками `Качество (Phred)`,
`Нуклеотиды`, `Длины ридов` и `Все графики` → на каждой вкладке отображается соответствующий график с
панелью масштабирования `matplotlib`.
3. **Drag & Drop (при установленном `tkinterdnd2`):** перетащите файл `data/test.fastq` из файлового
менеджера на окно программы → файл автоматически загрузится и перерисует графики.
4. **Проверка некорректного файла:** попробуйте открыть или перетащить файл не того формата (например,
`.txt`) или повреждённый FASTQ → программа покажет понятное предупреждение или сообщение об ошибке из
`FastqReader`.
5. **Сохранение графиков и CLI-режим:** нажмите `Сохранить PNG` и выберите папку → в ней создадутся
файлы `per_base_quality.png`, `per_base_content.png` и `length_distribution.png`.
