# Практика по GUI на Tkinter (Тема 18)

Репозиторий содержит решения заданий по созданию графических интерфейсов на Python с использованием библиотеки `tkinter`.

## Состав проекта
- `calculator.py` — **Задание 18.1.1.** Калькулятор с поддержкой клавиатурного и кнопочного ввода.
- `patients_app.py` — **Задание 18.1.2.** Форма учёта пациентов с расчётом ИМТ, сохранением в JSON и сводной статистикой.
- `README.md` — описание проектов, инструкции по запуску и воспроизводимые примеры.

## Установка зависимостей
Для `calculator.py` дополнительные пакеты не нужны (используются только встроенные модули `tkinter` и `math`).

Для `patients_app.py` используются:
- `matplotlib` — построение графиков сводной статистики;
- `faker` *(опционально)* — генерация реалистичных тестовых ФИО (если библиотека не установлена, используется встроенный запасной генератор).

```bash
pip install matplotlib faker
```

*(На Linux при отсутствии системного пакета Tk может потребоваться `sudo apt install python3-tk`.)*

## Задание 18.1.1 — Калькулятор (`calculator.py`)

Графический калькулятор на `tkinter`.

### Возможности
- Ввод выражений как с клавиатуры, так и с помощью кнопочной панели (`0`–`9`, `.`, `+`, `-`, `*`, `/`, `sqrt`, `C`, `DEL`, `=`).
- Горячие клавиши: `Enter` — вычислить (`=`), `Esc` — очистить (`C`).
- Собственный разбор и вычисление выражений без `eval()` с учётом приоритета операций (`*` и `/` выполняются раньше `+` и `-`).
- Валидация ввода: пустая строка, недопустимые символы, лишние десятичные точки, два знака операции подряд, незавершённые выражения.
- Обработка исключений: деление на ноль и извлечение квадратного корня из отрицательного числа.

### Запуск
```bash
python calculator.py
```

### Минимальные воспроизводимые примеры
1. **Приоритет операций:** введите `2 + 3 * 4` и нажмите `=` (или `Enter`) → результат `14`.
2. **Смешанный ввод (клавиатура + кнопки):** введите с клавиатуры `15`, нажмите кнопку `/`, введите `3`, нажмите `=` → результат `5`.
3. **Квадратный корень:** введите `25` и нажмите кнопку `sqrt` → `sqrt = 5`.
4. **Редактирование и очистка:** кнопка `DEL` удаляет один последний символ, `C` (или `Esc`) полностью очищает поле.
5. **Деление на ноль:** введите `10 / 0` и нажмите `=` → сообщение `Ошибка: Деление на ноль невозможно.`.
6. **Корень из отрицательного числа:** введите `-9` и нажмите `sqrt` → сообщение `Ошибка: Нельзя извлечь квадратный корень из отрицательного числа.`.
7. **Валидация некорректного ввода:** введите `abc` и нажмите `=` → сообщение `Ошибка: Недопустимый символ: 'a'.`.

## Задание 18.1.2 — Формы учёта-отчёта (`patients_app.py`)

Приложение для ведения таблицы пациентов, автоматического расчёта индекса массы тела (ИМТ) и визуализации сводной статистики.

### Возможности
- Таблица пациентов (`ttk.Treeview`) с полями: `ФИО`, `Возраст`, `Пол`, `Рост (см)`, `Вес (кг)`, `ИМТ` и сортировкой по клику на заголовок столбца.
- Модальная форма добавления и редактирования пациента с отдельными полями `Фамилия*`, `Имя*`, `Отчество (при наличии)`, выбором пола (`Мужской`, `Женский`, `Не определён`) и проверкой корректности ввода.
- Автоматический расчёт ИМТ по формуле `вес (кг) / (рост (м))²`.
- Сохранение данных в файл `patients.json` при каждом изменении и автоматическая загрузка при запуске программы.
- Кнопка `Примеры (+20)` для быстрой генерации тестовых записей (`faker` / `random`).
- Кнопка `Статистика` — окно с 4 графиками `matplotlib`:
  1. Распределение пациентов по полу.
  2. Распределение пациентов по возрасту.
  3. Распределение ИМТ с учётом пола.
  4. Зависимость ИМТ от возраста.

### Запуск
```bash
python patients_app.py
```

### Минимальные воспроизводимые примеры
1. **Добавление пациента и расчёт ИМТ:** нажмите `Добавить`, заполните `Фамилия`: `Иванов`, `Имя`: `Пётр`, оставьте `Отчество` пустым, возраст `30`, пол `Мужской`, рост `180`, вес `81`, нажмите `Сохранить` → в таблице появится строка `Иванов Пётр` с `ИМТ = 25.00`.
2. **Третий вариант пола:** выберите в поле `Пол` значение `Неопределён` → запись корректно сохраняется и отображается на всех графиках статистики.
3. **Валидация формы:** оставьте обязательное поле `Фамилия` пустым или введите буквы в поле `Возраст` → появится сообщение об ошибке, некорректная запись не сохранится.
4. **Редактирование и сохранение в файл:** выберите строку, нажмите `Редактировать` (или дважды кликните по строке), измените вес и сохраните → пересчитается ИМТ и обновится `patients.json`; после перезапуска программы все данные сохранятся.
5. **Генерация выборки и статистика:** нажмите `Примеры (+20)`, затем `Статистика` → откроется окно с 4 графиками по всем добавленным пациентам.
